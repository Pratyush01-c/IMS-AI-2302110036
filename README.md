## 📅 Day 10 – One Function, Many Products 🔋

**File:** `battery_cells.py`

Created a reusable product configuration system using Python dataclasses.

### Features:
- Defined a `CellSpec` dataclass.
- Stored battery cell dimensions (radius and height) together.
- Added specifications for 18650, 21700 and 4680 battery cells.
- Used dictionaries to manage multiple product variants.
- Applied loops to create repeated CAD features.
- Used parameters to resize designs for different product variants.

**Concepts Learned:**
- Python dataclasses
- Dictionaries
- Reusable functions
- Product parameterization
- Loops and geometric transformations
- CAD automation
